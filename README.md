# devops-handy-tools

A collection of lightweight, production-ready shell scripts for daily DevOps tasks and workflow automation.

## Philosophy
- **Scripts over Functions**: Each tool is a standalone script for better environment isolation and easier debugging.
- **Minimalist & Stable**: Built with core Linux utilities (sed, tr, awk) to ensure compatibility across different distributions.
- **Practical**: Solving real-world problems from content creation to system maintenance.

# shell command
- **dns**: Helps you better view your network throughput and current network speed performance
- **cls**: Clean screen and use sudo cls can Optimize your cpu and disk cache files to make your system faster
- **lc**:  Find your file totals very easy
- **mem**: Optimize your memory and make your system faster
- **port**: Search all related ports
- **replace-text**: Replace text command, very simple to use
- **wireshark-serv**: Make data capture easier and more convenient. Start the cfg parameters directly, and it will automatically help you complete the configuration. Then run or start will monitor and capture the chrome browser data.
- **escp**: Make file transfer very simple and convenient, just follow the prompts, you can easily push and pull files, and you can also set up automated scripts for scheduled task processing
- **essh**: Make the ssh command more stable, able to connect continuously without interruption, and compatible with all old system versions
- **howdy-fix-compare**: Auto fix the python high or low version bring the bugs for howdy application
